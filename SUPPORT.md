# Support

This fork is maintained by one person in their own time (see [GOVERNANCE.md](GOVERNANCE.md)), so support is best-effort, not a contract. The upstream project, [lowlighter/metrics](https://github.com/lowlighter/metrics), is no longer maintained, and nothing here is sent back to it.

## Getting help

- **Questions and ideas:** [Discussions](https://github.com/HoneyBearTech/metrics/discussions).
- **Bugs:** an [issue](https://github.com/HoneyBearTech/metrics/issues/new/choose) with the bug report form. Say which commit or ref you use, what you expected and what happened.
- **Security vulnerabilities:** never in a public issue; see [SECURITY.md](SECURITY.md).
- **Documentation:** [docs/](docs/README.md), starting with the [quick start](docs/quick-start.md).

## What is supported

The fork makes no releases or images. Only the latest commit on `master` is supported, and fixes land there first. If you use the action from another commit or ref, move to the latest `master` before asking for help ([docs/upgrading.md](docs/upgrading.md)).

Some plugins depend on third-party websites and APIs that change without notice. A plugin that has broken that way may stay broken (see [docs/roadmap.md](docs/roadmap.md)).
