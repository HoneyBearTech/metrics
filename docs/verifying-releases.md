# Verifying releases

**Planned.** This fork has made no releases and publishes no images, so there is nothing to verify yet.

What you can check today is the source itself: use the action by full commit hash and read the commits you adopt. Commits on `master` are made through pull requests, and Renovate's commits are signed by GitHub.

When releases start, this page will describe how to check them: signed tags, checksums and signed provenance. Signed releases are on the [roadmap](roadmap.md) as a later job.
