# User guide

The guides are generated from the plugin and template descriptions, so they live next to the code:

- [Plugins](../../source/plugins/README.md): every plugin, what it shows, its inputs and examples. Each plugin has its own `README.md` in `source/plugins/<name>/`.
- [Templates](../../source/templates/README.md): the look of the image. Each has its own `README.md` in `source/templates/<name>/`; [community templates](../../source/templates/community/README.md) explain how to add one.
- [Core options](../../source/plugins/core/README.md): output format, filename, output action, retries and the other general options.
- [The base plugin](../../source/plugins/base/README.md): the header, repositories and other sections shown by default.

Setup guides: [action](../../.github/readme/partials/documentation/setup/action.md), [web server](../../.github/readme/partials/documentation/setup/web.md), [Docker](../../.github/readme/partials/documentation/setup/docker.md) and [local development](../../.github/readme/partials/documentation/setup/local.md). Where they name the upstream project's images, branches or shared instance, those don't apply to this fork (see [installing](../installing.md)).
